# AI 产品能力矩阵

本资料是作品集使用的合成产品资料，不代表任何真实厂商的商业承诺。演示系统只允许基于本资料输出能力匹配，不允许把未出现的价格、SLA 或认证当作事实。

## 企业知识库与方案助手

平台支持将 PDF、DOCX、PPTX、表格和 Markdown 等资料纳入知识库，通过切分、向量检索、关键词召回和重排序为大模型提供上下文。回答应保留来源片段，无法召回证据时返回“资料不足”，并提出澄清问题。

## 工作流能力

工作流可以依次完成需求提取、知识检索、结构化输出、条件分支和结果展示。对于客户的部署方式、数据出域、并发量、延迟和合规要求，应在生成方案前完成结构化校验。

## 模型与接口

平台可以连接云端模型、OpenAI-compatible API 和自托管推理服务。应用 API 由服务端调用，浏览器端不得直接携带模型或应用密钥。返回结果建议使用 JSON Schema 约束，便于接入 CRM、工单和售前方案模板。

## 售前输出边界

系统可以生成需求摘要、候选架构、实施步骤、资料引用、风险和待确认问题。系统不能根据演示资料自行承诺价格、法律合规、服务等级、准确率或最终容量；这些内容必须标记为待核验或进入人工审核。
