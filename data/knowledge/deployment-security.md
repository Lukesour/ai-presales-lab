# 部署与安全约束

## 部署模式

公有云 API 适合快速验证和弹性扩展，客户数据需要按照出域政策脱敏。私有化部署适合数据不能出域、需要内网访问或已有 GPU 资源的客户，但客户需要承担模型文件、硬件、升级、监控和运维成本。

本地 Apple Silicon 设备适合个人演示、边缘推理和小规模验证，不应直接据此承诺企业生产环境的并发能力。生产选型应重新测试目标硬件、模型、上下文长度和并发量。

## 安全设计

知识库应按租户或项目隔离，并设置文档访问权限。敏感资料不应写入公开日志或提交到 GitHub。API Key 只能保存在服务端环境变量或密钥管理系统中。需要记录请求审计、模型版本、知识库版本和人工审核结果。

## 需求澄清

并发量应区分平均并发和峰值并发，延迟应区分首 Token 延迟和完整答案延迟。合规需求应明确数据驻留、个人信息、日志留存、加密、访问控制和供应商审计边界。
