# 本地推理服务选型资料

llama.cpp 是一个面向多种硬件的 C/C++ 推理项目。它支持 GGUF 模型、量化推理、Apple Silicon 的 ARM/Accelerate/Metal 优化，以及 OpenAI-compatible 的服务端接口。

量化通常可以降低模型文件大小和内存占用，并可能提高推理速度，但不同量化等级会在输出质量、速度和资源占用之间产生取舍。Q4、Q5、Q8 的差异必须通过目标任务和目标硬件实测，不能只根据文件大小判断。

本地模型服务适合数据不能出域、网络不稳定、边缘设备或需要固定模型版本的场景。云端 API 适合快速上线、模型能力要求高或请求量弹性变化的场景。两者可以通过 OpenAI-compatible API 统一上层调用方式。

性能报告至少记录模型版本、量化等级、上下文长度、硬件、Metal/CPU 设置、首 Token 延迟、生成速度、并发数、p95 延迟和内存占用。单机演示数据不能直接等同于生产容量承诺。
